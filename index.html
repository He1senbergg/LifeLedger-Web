账户总余额走势

按所选年／月／日显示期末或截至最后记录的账户总余额，含已记录的投资、国债；估值前新增投入按成本计，估值记录会覆盖。外币按当前参考汇率折合 CNY；未记录的账户余额无法补齐。月份由旧到新，可左右滑动，点击圆点查看金额。

资产分布

现金存款、国债、投资（含黄金）按同一汇率折合人民币；与上方所选时间同步。

资产里程碑与日期测算

这是按固定收支与收益假设的情景测算，不是承诺日期。默认收益为0%；长期工资、支出和市场都会变化。已达标时间取最早可用月末记录，外币用当前参考汇率。

各账户明细

投资收益

收益＝当前持仓估值＋累计卖出到账＋现金分红－累计买入本金。收益率＝收益÷累计买入本金（非年化，不等于平台收益率）。历史估值未分平台，先按投资 / 国债 / 黄金汇算；相同基金跨平台不重复相加。

平台投入明细

仅拆分资金流，历史总估值没有可靠的平台分摊依据，暂不拆分平台收益。

GitHub 同步

共享账本保存在私有仓库 He1senbergg/LifeLedger。打开应用或保存账目时自动同步；断网时保留待同步修改。

此电脑使用现有 GitHub 登录，无需填写令牌。

其它设备首次使用：选择 LifeLedger 仓库，授予 Contents 读写权限。令牌仅用于这个仓库，不会写入账本或网站代码。

极空间备份

Windows 将最新账本导出到指定目录。仅更新账本.json、账本.xlsx、流水.csv。旧Excel保留已有存档，不再重复复制。备份明文保存、固定文件名、覆盖同名文件。

手机和 iPad 可记下备份请求，由运行中的 Windows 程序执行。电脑关机时，下次启动后补上。

诊断日志

记录同步、备份的时间、结果与耗时，不记录令牌或流水内容。设备本地保留最近300条；转储会把日志保存到私有账本仓库。Windows另保留轮转日志文件。

本地导出与恢复

浏览器缓存可能被清理，请保持同步。导出包含你的未同步修改；恢复时先下载当前账本留底。
